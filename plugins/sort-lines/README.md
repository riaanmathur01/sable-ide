# Sort Lines

Commands for the selected lines, or the whole file when nothing is
selected:

- **Sort Lines (A → Z)** / **(Z → A)**: natural order, so "item 2" comes
  before "item 10", and case is ignored
- **Sort Lines by Length**
- **Remove Duplicate Lines**: keeps the first of each
- **Reverse Lines**, **Shuffle Lines**

Every change is one undo step.

Permissions: `editor`.
