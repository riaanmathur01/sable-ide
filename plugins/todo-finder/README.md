# TODO Finder

Marks `TODO`, `FIXME`, `HACK`, `XXX` and `BUG` comments in the open file:
a squiggle in the editor and an entry in the Problems panel (FIXME, BUG
and HACK as warnings, the rest as notes). It updates when you open or
save a file.

Commands: **Find TODOs in This File**, **Clear TODO Marks**.

Permissions: `editor`.
