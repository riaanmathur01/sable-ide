## 💿 What is Synesthesia Synthwave?

Unleash a unique, musical coding experience: <br>
**4 dark themes** inspired by synesthesia (<i>when people literally see sound</i>) and 80s retrofuturism.
Every variant riffs on a different musical genre. Main "Synthwave" is your all-in synthpop.

🎛️ <b>Ultra-colorful. Hyper-legible. Music in every pixel.</b> 🎛️

## 🚀 Quick Install

```sh
# Marketplace Way
code --install-extension synesthesia-studio.synesthesia-theme

# Or manual (super geeky)
git clone https://github.com/stackmason1/synesthesia-theme/synesthesia-theme.git
cp -R synesthesia-theme ~/.vscode/extensions/
```

> Select **"Synesthesia Synthwave \*** as your theme. Then, press F11. Now you're in the 80s.

{
