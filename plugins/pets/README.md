# Pets

Little pixel-art pets that live in your sidebar while you code. They
wander about, sit, nap (with floating Zs), chase a ball you throw, and
say hello to each other with a heart when they meet.

There are nine kinds of pet, most in several colours: a dog, a cat, a
fox, a rubber duck, a crab, a snake, a bunny, a dragon and a panda.

## How to use

1. Open the **Plugin Views** section of the sidebar, or run **Pets: Show
   Pets** from the command palette: ⇧⌘P (Ctrl+Shift+P on
   Windows/Linux). A puppy is waiting for you there the first time.
2. Run **Pets: Add Pet…** to adopt another. Choose the kind of pet,
   then its colour, then a name. A random name is filled in, so you can
   just press Enter.
3. Click an empty spot to toss a ball, or drag and let go to fling it.
   The pets run after it, and whoever catches it brings it back to where
   you threw it. Leave the ball lying around and someone may nudge it
   along for a game. You can also pick the ball up and throw it again.
4. Click a pet to make it jump and say something. Hover over it to see
   its name, and double-click it to rename it.

Hover over the pets to show the buttons in the top-right corner: add a
pet, throw the ball, and change the scenery.

## Commands

| Command | |
| ------- | --- |
| **Pets: Add Pet…** | Adopt a pet: kind, colour and name |
| **Pets: Remove Pet…** | Send one pet home |
| **Pets: Remove All Pets** | Send every pet home (asks first) |
| **Pets: Throw Ball** | Throw a ball in from the side |
| **Pets: Rename Pet…** | Give a pet a new name |
| **Pets: Change Scenery…** | None, forest, beach or a starry night |
| **Pets: Pet Size…** | Small, medium or large |
| **Pets: Start Pet Coding Session** | Open your pets in an editor tab |
| **Pets: Show Pets** | Show the sidebar view |

The sidebar view and the editor tab show the same pets, so a pet you add
or rename shows up in both. Your pets, their names, the scenery and the
size are kept between sessions.

The pets fit themselves to the panel: in a short or narrow sidebar they
get smaller, and they stay inside the visible area. They stop moving
while the view is hidden, so they don't use the CPU then. If your system
asks for reduced motion, they move more slowly and jump less.

All the art (the pets, the ball and the scenery) is original, drawn
pixel by pixel by the plugin's own code. Inspired by vscode-pets, but it
uses none of its assets.

Permissions: none. Needs Sable 0.3.7 or newer.
