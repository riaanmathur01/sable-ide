# Insert Date, UUID & More

Commands that insert at the cursor (or replace the selection):

- **Insert Date**: `2026-10-10`
- **Insert Time**: `14:05`
- **Insert Date and Time**: ISO 8601 in UTC, e.g. `2026-10-10T08:35:12.345Z`
- **Insert Unix Timestamp**: `1791621312`
- **Insert UUID**: a random v4 UUID
- **Insert Lorem Ipsum**: a paragraph of placeholder text

Permissions: `editor`.
