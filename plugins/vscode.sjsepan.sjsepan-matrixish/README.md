# Matrixish Theme

Matrixish color theme for Code-OSS based apps (VSCode, Codium, code.dev, AzureDataStudio, TheiaIDE and Positron). Syntax Theme based on Matrix Theme by @UstymUkhman. Includes additional syntax themes (see Change Log).

Created by sjsepan.
