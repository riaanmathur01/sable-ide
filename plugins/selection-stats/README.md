# Selection Stats

Shows how many characters, words and lines you've selected, in the status
bar: **42 chars · 7 words · 2 lines**. Nothing shows when nothing is
selected.

## How to use

1. Select some text in the editor.
2. Read the counts in the status bar. They update as you change the
   selection.
3. Click elsewhere to deselect, and the counts disappear.

An emoji or accented letter counts as one character. Selecting whole
lines (say, by dragging down the line numbers) counts the lines you
selected, not the empty line after them.

Permissions: none. Needs Sable 0.3.6 or newer.
